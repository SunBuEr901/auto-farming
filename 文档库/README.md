## 维护规则

每次确认新发现时，先在《发现与变更记录》追加日期、现象、证据、处理、结果和待验证项，再更新受影响的操作说明。新专题加入本索引。不得把计划中的操作记为已通过，也不记录密码和认证密钥。

本约定同时写入项目根目录 `AGENTS.md`，供后续在本项目工作的助手遵循。

   arm/               原教程脚本、课程原件、同级文档
   sensors/ chassis/ host/   同级文档与源码缺口说明

集中正文手工维护；20 份同级副本由[工具](../tooling.md)生成，附来源、SHA-256 和适配本地位置的链接。模块 AGENTS 只路由，不自动加载整套正文。共享环境在需要的模块各有生成副本，属于明确管理的重复，不建立第二个编辑源。

根旧使用说明和旧文档库 README 保留短跳转；其他旧路径见清单，仓库内部引用已迁移。历史记录中的字面部署路径或旧组织描述仍作为当时证据，不用当前目录倒改历史。

# 小车基本文档与使用说明

版本：v2｜更新：2026-10-17｜最近设备证据：2026-10-11。旧版长文已按任务拆分，步骤、历史参考值和限制保存在下列专题。

## 操作路径

1. 阅读[状态](../status.md)，确认需要的能力是否验收，以及记录日期。
2. 查[硬件与接线](../environment/hardware.md)和[远程连接](remote-access.md)，使用前复核地址与设备映射。
3. 传感器任务按[软件环境](../environment/software.md)准备 Jetson 宿主机 Humble，再按[传感器指南](sensors.md)启动、查数据、停止。
4. 机械臂课程按[Noetic 教程指南](arm.md)进入独立容器，按该指南保存配置和停止。master、图形窗口、模型加载、仿真规划、真机控制分别验收。
5. [数据录制与回放](data-recording.md)仍为待验证模板；先复核磁盘和输出目录。
6. 出错时看[故障排查](../troubleshooting/README.md)。恢复底盘开发先补[自定义固件资料](../modules/chassis.md)。

这些流程用于已有记录的环境。启动成功不等于当前设备、底盘协议或停止行为已确认。固件、部署版本及整车导航缺口统一维护在[待验证清单](../pending.md)。

## 结束与交接

传感器在各启动终端按 `Ctrl+C` 后检查节点；机械臂按专题关闭助手、停止 master 和容器。关闭 SSH 窗口不能代替停止检查。真机停车与急停方法尚未验收，不能从上述软件停止步骤推断实物已安全停止。

新增事实写入对应专题并追加[变更记录](../changes/README.md)；原始数据留日期、条件、来源及归档位置。参考资料见[资料索引](../references/README.md)。本次迁移仅修改本地文档组织，没有连接设备。

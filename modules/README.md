# 模块入口

这里把任务相关文档副本与文件放在一起。`README.md` 和专题副本来自 `docs/`，每份开头标明维护源和校验值；`AGENTS.md` 只提供本目录的阅读路线。

| 模块 | 本地内容 | 入口 |

工程代码以后按实际模块放入对应目录。不要因为目录存在就把模块实现或设备验收记为完成。
